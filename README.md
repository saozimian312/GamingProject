# Block Defense Game

A Unity game that combines block placement and tower defense mechanics.

## Overview
The player buys and places different functional blocks to defend a central core from enemy waves across multiple levels.  
The goal is to protect the core, manage gold, and clear all levels.

## Main Features
- Three block types:
  - **Attack Block**
  - **Income Block**
  - **Heal Block**
- Enemy waves with different enemy types
- Core health and win/lose conditions
- Level progression across multiple levels
- Shop system with random offers
- Main menu with level selection
- In-game UI showing Wave, Gold, Level, and Core HP

## Game AI
Enemies spawn, move toward the core, and attack when they are in range.

## Content Generation
- Random shop offers
- Enemy wave spawning
- Multiple levels and progression

## Animation
Enemy models use movement animation through Unity Animator.

- **Game**: main gameplay scene
